# ExamDeck

Вебзастосунок для підготовки до іспитів: управління колодами, тренувальні сесії та аналітика прогресу.

## Основні можливості

- авторизація та профіль користувача
- робота з колодами і картками
- режим повторення з прогресом
- панель аналітики
- адмін-сторінка для керування даними

## Технології

- React + TypeScript
- Vite
- UI компоненти на базі shadcn/ui
- Supabase (аутентифікація та база даних)

## Запуск локально

1. Встановіть залежності:

```
npm install
```

2. Запустіть dev-сервер:

```
npm run dev
```

## Структура проєкту (скорочено)

- `src/pages` - сторінки застосунку
- `src/components` - UI компоненти та обгортки
- `src/data` - дані та типи
- `src/lib` - утиліти та інтеграції

## Налаштування

Налаштування Supabase описані в [supabase/schema.sql](supabase/schema.sql).
